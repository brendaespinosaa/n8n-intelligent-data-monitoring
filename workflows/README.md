# n8n Workflows

This directory contains the exported **n8n workflow definitions** used in the automated monitoring system.

## Contents

- Workflow JSON files exported from n8n
- Configurations representing ingestion, processing, and alerting logic

## Purpose

These files allow:
- Workflow versioning
- Reuse and portability
- Technical review of the automation logic

## Notes

- Credentials and secrets are not included
- Files are intended for demonstration and portfolio purposes
- Workflow logic aligns with the documented architecture and business rules
