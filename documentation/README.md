# Technical Documentation

This directory contains detailed technical documentation describing the system architecture and business logic.

## Contents

### architecture.md
Provides a high-level overview of the system architecture, including:
- Data sources
- Workflow structure
- Data processing
- Alerting mechanism
- Integrations

### business_rules.md
Defines the business rules applied within the workflow, including:
- Implemented rules
- Planned and extensible rules
- Alert severity levels
- Rule management strategy

## Objective

The documentation ensures transparency, maintainability, and clear communication between technical and non-technical stakeholders.
