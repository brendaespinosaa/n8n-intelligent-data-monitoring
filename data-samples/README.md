# Data Samples

This directory contains **fictional sample data** used exclusively for demonstration and testing purposes.

## Purpose

The sample data allows the workflow to be tested, shared, and reviewed without exposing real or sensitive information.

## Contents

- CSV or JSON files with mock data
- Structures that closely resemble real operational datasets
- Safe datasets for documentation and screenshots

## Data Policy

- No real data is included
- No personal or sensitive information is stored
- Data is used only for simulation and portfolio demonstration
